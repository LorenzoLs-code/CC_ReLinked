# CC: ReLinked
CC: ReLinked is an **addon** of the minecraft mod **ComputerCraft** that adds a few things and a **compatibility** with the [Drive-By-Wire (with sable)](https://modrinth.com/project/KsqvI0hD).

Available on [Modrinth](https://modrinth.com/project/cc_relinked/)

It adds the following stuff:
## Cable Hub
This block has a configurable amount of (**Drive-By-Wire**) **channels** that you can control via a cc peripheral.

## Data Sender & Data Glasses
These tow work in combination.
By **linking** the Data Glasses with the Data Sender and then equipping the glasses you have an **overlay** that is **controlable/customizable** via a cc peripheral
